# ⚡ KAWAKI CLI

Petit outil pratique pour Termux.

## Fonctionnalités

- 📱 Informations du téléphone
- 💾 Stockage
- 🌐 Réseau
- 🔋 Batterie
- 🔄 Mise à jour
- 🎨 Interface Termux

## Installation

```bash
pkg install git -y
git clone https://github.com/TON-PSEUDO/kawaki-cli.git
cd kawaki-cli
chmod +x install.sh
./install.sh
```

Puis :

```bash
kawaki
```

## Désinstallation

```bash
chmod +x uninstall.sh
./uninstall.sh
```
